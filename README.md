# Yanmar CRM (app cài đặt)

Giao diện Yanmar CRM dạng app cài lên màn hình chính điện thoại (PWA).
Dữ liệu nằm trong Google Sheet của từng đại lý, xử lý qua Apps Script. Kho này không chứa dữ liệu khách hàng hay passcode.

- `config.js`: đường link `/exec` của Apps Script.
- Sửa giao diện: sửa Index.html bên Apps Script rồi tạo lại `index.html` bằng script build.
